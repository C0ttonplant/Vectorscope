# ![vector](src/assets/icon.svg)
###### Simple flat crossplatform vectorscope
listens to your audio device, change color size and scale.

tested on zig version 0.16.0

## run and build
release fast recommended
```bash
zig build run -Doptimize=ReleaseFast
```

## Keybinds
- `H`   - toggle hide HUD
- `B`   - toggle hide window decorations
- `F11` - toggle fullscreen
